# DSA App Launchers

This directory contains standalone `.bat` launcher files for every desktop and web application in the project:

| Launcher | App Target | Description |
| :--- | :--- | :--- |
| **`Launcher_Menu.bat`** | **Master Console Menu** | Interactive menu to launch any app with a single keypress [1-4]. |
| **`1_DSA_Control_Centre.bat`** | **DSA Control Centre** | Dedicated window for managing students, promoting to Teacher, demoting staff, and inspecting progress (`http://localhost:5000/admin`). |
| **`2_DSA_Visualizer_PWA.bat`** | **DSA Visualizer Pro** | Standalone window for the Canvas algorithm visualizers, Sorting, Searching, Graphs, Trees (`http://localhost:5000/index.html`). |
| **`3_DSA_React_Client.bat`** | **React Web Client** | Starts the backend and the Create React App frontend on `http://localhost:3000`. |
| **`4_DSA_Electron_Desktop.bat`** | **Electron Desktop App** | Runs the Vite + React 19 Electron desktop application in `admin-web/`. |
